Full-Stack · Multi-User · Deployed

Gemini Meeting Prep — Executive Briefing Console

Reads a user’s Google Calendar and Gmail, then has Gemini write a briefing for each meeting. Live Google login is limited to whitelisted testers because of the restricted Gmail and Calendar scopes, so use the Demo Mode button to try it.

  • Cut meeting prep from 15 minutes to under 5 seconds with one FastAPI backend that joins Calendar, Gmail, and Gemini
  • Google OAuth 2.0 (PKCE), signed JWT sessions, and a PostgreSQL cache (SQLAlchemy), so each user sees only their own data and repeat requests return instantly
  • Multi-stage Dockerfiles and a render.yaml Blueprint deploy the frontend, backend, and database in one step
  • pytest tests for the backend

AI · Full-Stack · Deployed

UniHack — AI Student Knowledge Platform

A search tool where students find campus fixes other students already worked out. It searches a vector database of student tips first, then falls back to Gemini with web search when nothing matches.

  • FastAPI service on Pinecone, Gemini, LangChain, and FastEmbed; answers users confirm are saved back to the vector database, so the knowledge base grows without retraining
  • Results are filtered by university and location, and a bad match is blocked after three reports from different users
  • A 4-model Gemini fallback chain keeps the bot answering through rate limits
  • pytest tests for the service
Python FastAPI Pinecone Google Gemini LangChain FastEmbed JavaScript Render pytest
Live Demo GitHub

ML · AWS · Deployed

Dynamic Airline Ticket Pricing Engine

A fare prediction model trained on scraped Expedia itineraries and served from AWS Lambda.

  • RandomForestRegressor trained on ~95,000 flights reached $46.66 MAE (12.4% of average fare) on 18,992 held-out flights, reproduced independently on Kaggle
  • Error analysis found a weak spot on premium fares; new cabin features became the model’s second- and tenth-most-important predictors
  • Deployed on AWS Lambda with Docker, ECR, S3, and DynamoDB, and the live predictions matched training-time results exactly
  • pytest tests for the pipeline
